# Porting note

The direct port of the browser prototype (`index.html` + `villain.js`) to Godot 4.7 has been superseded. The first pass ported the data tables (`data/*.json`), stat math (`game/run.gd`), the controller-first input map (`game/controls.gd`), synth SFX (`fx/sfx.gd`), the arena with every cop type, effect and boss, and the design, shop, pause and game-over screens. The game was then rebuilt as a city heist campaign. At the user's request it is now back to the prototype's shape: one Brotato-sized arena, waves back to back, a shop between waves, a difficulty picker after the weapon design screen, and cosmetic wave themes (`levels/arena_level.gd`, `ui/difficulty_screen.gd`). The city, route map, heat progression and contracts are gone. The agreement with the character session still holds: the rig is `res://character/villain.tscn` with `set_state`, `set_items`, `muzzle_global`, `shoulder_global`, `off_muzzle_global`, `off_shoulder_global` and `anchor_global`, and the viewport is 960×540. Shop selling (`Run.sell_price`, `Run.sell_block_reason`, `Run.sell`) refunds 45% of the current price, one copy at a time.
